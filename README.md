# Monge's three-circle theorem in Lean 4

A Lean 4 + Mathlib formalisation of **Monge's theorem** for three circles, in coordinates over an
arbitrary field.

> For three circles with centres `O₁, O₂, O₃` and pairwise distinct radii `r₁, r₂, r₃`, the three
> external centres of similitude `S₁₂, S₂₃, S₃₁` are collinear.

Here `ext O₁ O₂ r₁ r₂ = (r₁·O₂ − r₂·O₁)/(r₁ − r₂)` is the external centre of similitude and
`det3 A B C` is the signed double area. This is **not** Mathlib's `MongePoint` (the Monge point of a
simplex), which is a different theorem and is not used.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 7 named declarations.

## Main statements

| Lean name | File:line | Statement |
|---|---|---|
| `Monge.ext` | `Monge/Basic.lean:31` | external centre of similitude |
| `Monge.det3` | `Monge/Basic.lean:36` | signed double area (collinearity criterion) |
| `Monge.monge` | `Monge/Basic.lean:42` | Monge's theorem: `r₁ ≠ r₂`, `r₂ ≠ r₃`, `r₃ ≠ r₁` ⇒ `det3 S₁₂ S₂₃ S₃₁ = 0` |
| `Monge.monge_example` | `Monge/Basic.lean:54` | non-vacuity: centres `(0,0), (4,0), (0,3)`, radii `1, 2, 3` over `ℚ` |
| `Monge.monge_example_values` | `Monge/Basic.lean:61` | the example's centres are `(−4,0), (12,−6), (0,−3/2)` (non-degenerate) |

The equal-radius case (a centre at infinity) is excluded by the hypotheses and is not formalised;
neither is the internal centre of similitude.

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for 5 named
declarations, fully qualified (every declaration cited in `SPIKE_REPORT.md`, plus every name
queried by the axiom scratch file `scratch/Ax.lean`). The queries are generated by the gate itself, not read
from a file in the repository.

The gate fails if any of the following is true:
- a source file (`Monge/*.lean`, `Monge.lean`) contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `initialize`, `IO`, `set_option`, `macro`/`elab`/`syntax`/`notation`/`infix`/`prefix`/`postfix`, `import Lean` or `open Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (7 declarations, standard axioms only)`. Some of these are definitions, which may
use a subset of the three axioms.

`tests/tamper.sh` plants six kinds of fake proof in scratch copies (in `Monge/Basic.lean`) and checks
that the gate rejects each one (a rejection must exit nonzero and print the expected `FAIL`
message). The real repository is never modified.

| Test | What it plants |
|---|---|
| sorry | a `sorry` |
| ax2line | an axiom split across two lines |
| evalfake | an `#eval` that prints a fake axiom report |
| macro | a custom macro that rewrites `#print axioms` |
| falsehyp | the hypothesis `r₁ ≠ r₂` dropped from `monge` (false: with `r₁ = r₂` the centre collapses to `(0,0)` via `x/0 = 0`) |
| wrap | a genuine extra axiom with a long name, so the report wraps over several lines |

`tests/tamper.sh` needs a prior `lake build` (it reuses `.lake/build`); run the tests one at a time.

`python3 code/check_monge.py` checks the theorem on 2000 random rational configurations, with a
negative control (arbitrary points on the lines `OᵢOⱼ`). `SPIKE_REPORT.md` is the development log.

## Prior art

`docs/1000.yaml` in Mathlib lists "Monge's theorem" with no declaration. GitHub code search for
`monge` in Lean found only Mathlib's Monge point of a simplex and an unrelated optimal-transport
file; Mathlib PR #43646 is also about the Monge point of a simplex. Searches of the Isabelle AFP,
HOL Light, Coq and Mizar found no formalisation of the three-circle theorem. As far as these
searches go, this is the first formal proof of the theorem; the searches are not exhaustive.

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Toolchain: Lean `v4.33.1`, Mathlib `v4.33.1` (revision pinned in `lake-manifest.json`).
`gate.sh` never fetches: run `lake exe cache get` (or `lake build`) first so that the pinned
Mathlib checkout is present in `.lake/packages`.

## Note on how this was produced

The formal proofs, checking scripts and documentation were developed with the help of a
large-language-model AI assistant. The author directed the work, reviewed the statements, and is
responsible for the result. The Lean kernel checks every proof.
